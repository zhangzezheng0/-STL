# Tine c++ STL

A hand rubbed lite version of the C++ standard template library. This project mainly simulates vector, list, deque, hashtable red-black tree and other commonly used containers, and implements their iterator function, which can be used in conjunction with containers. Performance tests and functional tests were conducted, the test coverage reached 100%, and its performance is slightly better than the C++ STL in most aspects.
